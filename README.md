# Paired Dirac domains and boundary response

Research repository for a candidate mathematical paper on paired Dirac
operator domains, mass/logarithmic metric variations, and boundary response.
The manuscript, proof audit, novelty assessment, and Lean certification are
in progress and no publication or certified theorem is claimed here.

The recorded scientific starting point is the rough paired-variation note at
[scientific commit f0eab590](https://github.com/Quantyra/quantyra-wormhole-semiclassical/blob/f0eab59063422c80ccc7c8e281170c75cc3afc71/notes/current-rough-paired-variation.md).
That source distinguishes a fixed-domain operator calculation and a flat
local tangent response from an unproved regulator-uniform curved trace
remainder. Its claims remain subject to a paper-specific audit.

Lean development and verification for this project must run on GCP under
Quantyra Space's established protocol. A repository or a future GitHub
release is not by itself proof of a theorem or Lean certification.
